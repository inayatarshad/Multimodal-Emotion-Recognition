# Paper

```bash
make figures      # regenerate figures/ from experiments/results/*.json
latexmk -pdf main.tex
```

**Never edit a figure by hand.** They are generated from the committed results JSON, so a
figure cannot drift from the numbers it depicts. If a figure looks wrong, the results are
wrong or the generator is — fix `src/wfb/reporting/figures.py`.

| `fig4_pareto.png` | `pareto_figure` | Robustness Pareto with mitigation arrows (Q3) |

Figures 3 and 4 need at least three architectures with results; the generator returns
`None` and skips rather than drawing a misleading two-point trend.

All figures use the Okabe–Ito colourblind-safe palette and vary marker and dash pattern
alongside colour, so they survive greyscale printing.

## Target venue

A workshop at **ICMI** (International Conference on Multimodal Interaction) — the natural
home for this work, and naming it in a MULTICOM motivation letter signals familiarity with
the field.

Preprint: arXiv cs.CL / cs.LG. First-time arXiv submitters need endorsement in cs
categories, so **start asking early**. Fallback if endorsement does not arrive in time: a
well-typeset PDF technical report in this directory, linked from the README, which retains
most of the CV value.
